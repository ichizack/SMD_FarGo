Objetivo do programa:
- Organizar pedidos de insumos, bem como estoque dos mesmos, para o setor de enfermagem;
- Facilitar a comunicação entre quem pede os insumos e quem atenderá a entrega dos mesmos.

Púlico-alvo
- Profissionais do setor de enfermagem e do setor de estoque;

Considerações gerais:
- A identificação dos stakeholders e a definição do público-alvo foram baseadas em como cada grupo contribui para o sucesso do projeto. A aplicação tem como foco principal simplificar e otimizar os processos de pedidos e entregas de insumos, garantindo uma experiência mais ágil e precisa para todos os envolvidos.
